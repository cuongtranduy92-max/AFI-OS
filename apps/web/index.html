Sao lưu cơ sở dữ liệu

Tạo bản sao SQLite nhất quán, có SHA-256, kiểm tra toàn vẹn, khóa liên kết và phiên bản schema.

File backup nằm trong AFI-OS/backups/. Update không được ghi đè thư mục data/.

Khôi phục

Khôi phục cần dừng server nên được làm bằng file command, không làm âm thầm trong trình duyệt.

  1. Đóng AFI-OS hoặc để script tự dừng.
  2. Mở RESTORE-LATEST-BACKUP.command trong thư mục AFI-OS.
  3. Gõ RESTORE khi được hỏi. Hệ thống bỏ qua backup hỏng/sai schema và tự tạo backup khẩn cấp trước.
Chỉ dùng Restore khi dữ liệu lỗi hoặc update thất bại. Bình thường không cần mở file này.
